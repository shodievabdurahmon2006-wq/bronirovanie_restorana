
# 05. Лоиҳакашии пойгоҳи додаҳо

## 1. Муқаддима

Лоиҳакашии пойгоҳи додаҳо яке аз марҳилаҳои муҳими таҳияи системаи вебии бронированияи мизҳо дар тарабхона мебошад.

Мақсади ин марҳила муайян намудани сохтори маълумот, ҷадвалҳо, атрибутҳо, калидҳои аввалия ва хориҷӣ, инчунин робитаҳои байни ҷадвалҳо мебошад.

Пойгоҳи додаҳо бояд нигоҳдорӣ, ҷустуҷӯ, тағйирдиҳӣ ва коркарди маълумоти истифодабарандагон, мизҳои тарабхона ва фармоишҳоро таъмин намояд.

## 2. Мақсади лоиҳакашӣ

Мақсади асосӣ таҳияи модели сохтории пойгоҳи додаҳо мебошад, ки талаботи функсионалии системаи бронированияро таъмин мекунад.

Вазифаҳои асосӣ:

- муайян намудани объектҳои асосии система;
- муайян намудани атрибутҳои ҳар як объект;
- муайян намудани калидҳои аввалия ва хориҷӣ;
- муайян намудани робитаҳои байни ҷадвалҳо;
- пешгирӣ намудани такроршавии маълумот;
- таъмин намудани якпорчагӣ ва дурустии маълумот;
- пешгирӣ намудани бронированияи такрории як миз дар вақти якхела.

## 3. Муайян намудани объектҳои асосӣ

Дар модели ибтидоии пойгоҳи додаҳо се объекти асосӣ муайян карда шудаанд.

| № | Номи ҷадвал | Таъинот |
|---|---|---|
| 1 | users | Нигоҳдории маълумоти истифодабарандагон |
| 2 | dining_tables | Нигоҳдории маълумоти мизҳои тарабхона |
| 3 | reservations | Нигоҳдории маълумоти фармоишҳо |

## 4. Сохтори ҷадвали users

Ҷадвали `users` маълумоти ҳамаи истифодабарандагони системаро нигоҳ медорад.

Ба ин гурӯҳ мизоҷон, кормандон ва маъмур дохил мешаванд.

| Атрибут | Навъи дода | Маҳдудият | Тавсиф |
|---|---|---|---|
| id | INT | PK, AUTO_INCREMENT | Рақами ягонаи истифодабаранда |
| full_name | VARCHAR(150) | NOT NULL | Ному насаб |
| email | VARCHAR(255) | UNIQUE | Суроғаи почтаи электронӣ |
| phone | VARCHAR(30) | NULL | Рақами телефон |
| password_hash | VARCHAR(255) | NOT NULL | Пароли рамзгузоришуда |
| role | VARCHAR(20) | NOT NULL | Нақши истифодабаранда |
| created_at | DATETIME | NOT NULL | Санаи бақайдгирӣ |
| updated_at | DATETIME | NOT NULL | Санаи навсозии маълумот |

Нақшҳои истифодабарандагон:

- `customer` — мизоҷ;
- `employee` — корманд;
- `admin` — маъмур.

## 5. Сохтори ҷадвали dining_tables

Ҷадвали `dining_tables` маълумотро дар бораи мизҳои воқеии тарабхона нигоҳ медорад.

| Атрибут | Навъи дода | Маҳдудият | Тавсиф |
|---|---|---|---|
| id | INT | PK, AUTO_INCREMENT | Рақами ягонаи миз |
| table_number | VARCHAR(20) | UNIQUE, NOT NULL | Рақами миз |
| capacity | INT | NOT NULL | Шумораи ҷойҳо |
| location | VARCHAR(100) | NULL | Ҷойгиршавии миз |
| description | TEXT | NULL | Тавсифи миз |
| status | VARCHAR(20) | NOT NULL | Ҳолати миз |
| created_at | DATETIME | NOT NULL | Санаи илова |
| updated_at | DATETIME | NOT NULL | Санаи навсозӣ |

Ҳолатҳои миз:

- `active` — миз барои фармоиш дастрас аст;
- `inactive` — миз муваққатан барои фармоиш дастрас нест.

Майдони `capacity` шумораи максималии меҳмононро муайян мекунад.

## 6. Сохтори ҷадвали reservations

Ҷадвали `reservations` маълумоти фармоишҳои мизоҷонро нигоҳ медорад.

| Атрибут | Навъи дода | Маҳдудият | Тавсиф |
|---|---|---|---|
| id | INT | PK, AUTO_INCREMENT | Рақами фармоиш |
| user_id | INT | FK, NOT NULL | Идентификатори мизоҷ |
| table_id | INT | FK, NOT NULL | Идентификатори миз |
| reservation_start | DATETIME | NOT NULL | Сана ва вақти оғози фармоиш |
| reservation_end | DATETIME | NOT NULL | Сана ва вақти анҷоми фармоиш |
| guests_count | INT | NOT NULL | Шумораи меҳмонон |
| status | VARCHAR(20) | NOT NULL | Ҳолати фармоиш |
| comment | TEXT | NULL | Шарҳи иловагии мизоҷ |
| reviewed_by | INT | FK, NULL | Корманди баррасикарда |
| reviewed_at | DATETIME | NULL | Вақти баррасии фармоиш |
| rejection_reason | TEXT | NULL | Сабаби рад кардани фармоиш |
| created_at | DATETIME | NOT NULL | Санаи эҷоди фармоиш |
| updated_at | DATETIME | NOT NULL | Санаи навсозии фармоиш |

Ҳолатҳои фармоиш:

- `pending` — фармоиш интизори баррасӣ мебошад;
- `confirmed` — фармоиш тасдиқ шудааст;
- `rejected` — фармоиш рад шудааст;
- `cancelled` — фармоиш бекор карда шудааст;
- `completed` — фармоиш иҷро шудааст.

## 7. Робитаҳои байни ҷадвалҳо

Дар модели пойгоҳи додаҳо робитаҳои зерин муайян карда мешаванд.

### 7.1. users ва reservations

Навъи робита: One-to-Many (1:N).

Як мизоҷ метавонад якчанд фармоиш дошта бошад, аммо ҳар як фармоиш танҳо ба як мизоҷ тааллуқ дорад.

Калиди хориҷӣ:

`reservations.user_id → users.id`

### 7.2. dining_tables ва reservations

Навъи робита: One-to-Many (1:N).

Як миз метавонад дар сана ва вақтҳои гуногун якчанд фармоиш дошта бошад, аммо ҳар як фармоиш ба як мизи муайян вобаста аст.

Калиди хориҷӣ:

`reservations.table_id → dining_tables.id`

### 7.3. users ва reservations (баррасии фармоиш)

Навъи робита: One-to-Many (1:N).

Як корманд метавонад якчанд фармоишро баррасӣ кунад. Ҳар як фармоиш метавонад аз ҷониби як корманд баррасӣ шавад.

Калиди хориҷӣ:

`reservations.reviewed_by → users.id`

Ин майдон то лаҳзаи баррасии фармоиш метавонад NULL бошад.

## 8. Қоидаҳои якпорчагии маълумот

Барои таъмин намудани дурустии маълумот қоидаҳои зерин муайян карда мешаванд:

1. Ҳар як истифодабаранда бояд идентификатори ягона дошта бошад.
2. Суроғаи email набояд такрор шавад.
3. Ҳар як миз бояд рақами ягона дошта бошад.
4. Шумораи ҷойҳои миз бояд аз сифр зиёд бошад.
5. Шумораи меҳмонон бояд аз сифр зиёд бошад.
6. Вақти анҷоми фармоиш бояд аз вақти оғози он дертар бошад.
7. Фармоиш бояд ба миз ва истифодабарандаи мавҷуда вобаста бошад.
8. Мизоҷ набояд мизи ғайрифаъолро фармоиш диҳад.
9. Шумораи меҳмонон набояд аз иқтидори миз зиёд бошад.
10. Фармоиши бекоршуда ё радшуда набояд мизро банд нигоҳ дорад.

## 9. Пешгирӣ намудани бронированияи такрорӣ

Яке аз талаботи муҳими система пешгирӣ намудани фармоиши як миз барои якчанд мизоҷ дар як фосилаи вақти ҳампӯш мебошад.

Барои муайян намудани ҳампӯшии вақт шарти зерин истифода мешавад:

`existing_start < requested_end AND existing_end > requested_start`

Ин шарт нишон медиҳад, ки оё фосилаи нави фармоиш бо фармоиши мавҷуда бурида мешавад ё не.

Фармоишҳои дорои ҳолати `pending` ва `confirmed` ҳангоми санҷиши дастрасии миз ба ҳисоб гирифта мешаванд.

Барои пешгирӣ намудани хатогиҳо ҳангоми ҳамзамон фиристодани якчанд дархост, санҷиши дастрасӣ ва сабти фармоиш бояд дар дохили транзаксияи пойгоҳи додаҳо иҷро карда шаванд.

## 10. Талабот ба оптимизатсия

Барои беҳтар намудани суръати иҷрои дархостҳо индексҳо пешбинӣ мешаванд:

- `users.email` — барои ҷустуҷӯи истифодабаранда;
- `dining_tables.table_number` — барои ҷустуҷӯи миз;
- `reservations.user_id` — барои гирифтани фармоишҳои мизоҷ;
- `reservations.table_id` — барои гирифтани фармоишҳои миз;
- `reservations.status` — барои филтр кардани фармоишҳо аз рӯи ҳолат;
- `reservations.reservation_start` — барои ҷустуҷӯи фармоишҳо аз рӯи вақт.

## 11. Амният ва ҳифзи маълумот

Ҳангоми кор бо маълумоти истифодабарандагон талаботи зерин риоя карда мешаванд:

- паролҳо дар шакли кушода нигоҳ дошта намешаванд;
- барои нигоҳдории паролҳо алгоритми бехатари хешкунӣ истифода мешавад;
- ҳуқуқи дастрасӣ аз рӯи нақши истифодабаранда муайян карда мешавад;
- маълумоти фармоишҳо танҳо аз ҷониби истифодабарандагони дорои иҷозат тағйир дода мешавад;
- калидҳои хориҷӣ барои нигоҳ доштани робитаҳои дуруст истифода мешаванд.

## 12. Хулоса

Дар натиҷаи марҳилаи лоиҳакашии пойгоҳи додаҳо сохтори ибтидоии системаи бронированияи мизҳо муайян карда шуд.

Модели пешниҳодшуда аз се ҷадвали асосӣ иборат буда, маълумоти истифодабарандагон, мизҳои тарабхона ва фармоишҳоро нигоҳ медорад.

Ин сохтор барои таҳияи ER-диаграмма, модели мантиқӣ ва скриптҳои SQL замина фароҳам меорад.
