
# 06. Модели мантиқии пойгоҳи додаҳо

## 1. Муқаддима

Модели мантиқии пойгоҳи додаҳо марҳилаи гузариш аз модели консептуалӣ ба сохтори муносибатии маълумот мебошад.

Дар ин марҳила объектҳои муайяншуда дар ER-диаграмма ба муносибатҳо (ҷадвалҳо) табдил дода мешаванд. Барои ҳар як муносибат атрибутҳо, калиди аввалия, калидҳои хориҷӣ ва маҳдудиятҳои якпорчагӣ муайян карда мешаванд.

Модели мантиқӣ барои таҳияи сохтори физикии пойгоҳи додаҳо ва скриптҳои SQL асос мегардад.

## 2. Муносибатҳои пойгоҳи додаҳо

Модели мантиқии система аз се муносибати асосӣ иборат мебошад:

1. USERS
2. DINING_TABLES
3. RESERVATIONS

### 2.1. Муносибати USERS

Таъинот: нигоҳдории маълумоти истифодабарандагони система.

Сохтори муносибат:

USERS(
    id,
    full_name,
    email,
    phone,
    password_hash,
    role,
    created_at,
    updated_at
)

Калиди аввалия:
- PK: id

Маҳдудиятҳо:
- email — UNIQUE;
- full_name — NOT NULL;
- password_hash — NOT NULL;
- role — NOT NULL.

Қиматҳои имконпазири role:
- customer;
- employee;
- admin.

### 2.2. Муносибати DINING_TABLES

Таъинот: нигоҳдории маълумоти мизҳои тарабхона.

Сохтори муносибат:

DINING_TABLES(
    id,
    table_number,
    capacity,
    location,
    description,
    status,
    created_at,
    updated_at
)

Калиди аввалия:
- PK: id

Маҳдудиятҳо:
- table_number — UNIQUE;
- capacity — NOT NULL;
- capacity > 0;
- status — NOT NULL.

Қиматҳои имконпазири status:
- active;
- inactive.

### 2.3. Муносибати RESERVATIONS

Таъинот: нигоҳдории маълумоти фармоишҳои мизоҷон.

Сохтори муносибат:

RESERVATIONS(
    id,
    user_id,
    table_id,
    reservation_start,
    reservation_end,
    guests_count,
    status,
    comment,
    reviewed_by,
    reviewed_at,
    rejection_reason,
    created_at,
    updated_at
)

Калиди аввалия:
- PK: id

Калидҳои хориҷӣ:
- FK: user_id → USERS(id);
- FK: table_id → DINING_TABLES(id);
- FK: reviewed_by → USERS(id).

Маҳдудиятҳо:
- user_id — NOT NULL;
- table_id — NOT NULL;
- reservation_start — NOT NULL;
- reservation_end — NOT NULL;
- guests_count — NOT NULL;
- reservation_end > reservation_start;
- guests_count > 0.

Қиматҳои имконпазири status:
- pending;
- confirmed;
- rejected;
- cancelled;
- completed.

Майдони reviewed_by метавонад NULL бошад, зеро фармоиши нав ҳанӯз аз ҷониби корманд баррасӣ нашудааст.

## 3. Муайян намудани калидҳо

Дар модели мантиқӣ ду намуди калид истифода мешаванд.

### 3.1. Калидҳои аввалия (Primary Keys)

Калиди аввалия барои муайян намудани ягонагии ҳар як сабти ҷадвал истифода мешавад.

| Ҷадвал | Калиди аввалия |
|---|---|
| USERS | id |
| DINING_TABLES | id |
| RESERVATIONS | id |

### 3.2. Калидҳои хориҷӣ (Foreign Keys)

Калидҳои хориҷӣ робитаи байни муносибатҳоро таъмин мекунанд.

| Ҷадвали манбаъ | Майдони FK | Ҷадвали мақсад | Майдони PK |
|---|---|---|---|
| RESERVATIONS | user_id | USERS | id |
| RESERVATIONS | table_id | DINING_TABLES | id |
| RESERVATIONS | reviewed_by | USERS | id |

## 4. Муайян намудани робитаҳо

### 4.1. USERS — RESERVATIONS

Навъи робита: One-to-Many (1:N).

Як истифодабаранда метавонад якчанд фармоиш эҷод кунад. Ҳар як фармоиш танҳо ба як истифодабаранда вобаста мебошад.

### 4.2. DINING_TABLES — RESERVATIONS

Навъи робита: One-to-Many (1:N).

Як миз метавонад дар фосилаҳои гуногуни вақт якчанд фармоиш дошта бошад. Ҳар як фармоиш ба як мизи муайян вобаста аст.

### 4.3. USERS — RESERVATIONS (reviewed_by)

Навъи робита: One-to-Many (1:N).

Як корманд метавонад якчанд фармоишро баррасӣ кунад. Ҳар як фармоиш метавонад аз ҷониби як корманд баррасӣ шавад ё то вақти баррасӣ корманди муайяншуда надошта бошад.

## 5. Қоидаҳои якпорчагии маълумот

Барои таъмини якпорчагии маълумот маҳдудиятҳои зерин истифода мешаванд:

- PRIMARY KEY — барои муайян намудани сабти ягона;
- FOREIGN KEY — барои нигоҳ доштани робитаҳои байни ҷадвалҳо;
- UNIQUE — барои пешгирӣ намудани такрори маълумоти ягона;
- NOT NULL — барои пешгирӣ намудани майдонҳои ҳатмии холӣ;
- CHECK — барои санҷидани дурустии қиматҳои майдонҳо.

Қоидаҳои иловагӣ:

1. Иқтидори миз бояд аз сифр зиёд бошад.
2. Шумораи меҳмонон бояд аз сифр зиёд бошад.
3. Вақти анҷоми фармоиш бояд аз вақти оғози он дертар бошад.
4. Шумораи меҳмонон набояд аз иқтидори миз зиёд бошад.
5. Миз бояд дар ҳолати active бошад.
6. Фармоиши тасдиқшуда набояд бо фармоиши дигари тасдиқшудаи ҳамон миз дар як фосилаи вақт бархӯрд кунад.
7. Фармоишҳои pending низ бояд ҳангоми санҷиши дастрасии миз ба ҳисоб гирифта шаванд.

## 6. Нормализатсияи маълумот

Нормализатсия барои кам кардани такроршавии маълумот ва пешгирии аномалияҳои воридкунӣ, тағйирдиҳӣ ва несткунӣ истифода мешавад.

### 6.1. Шакли якуми нормалӣ (1NF)

Ҳар як майдон бояд қимати атомӣ дошта бошад. Дар як майдон якчанд қимати мустақил нигоҳ дошта намешавад.

Дар модели пешниҳодшуда маълумоти мизоҷ, миз ва фармоиш дар майдонҳои алоҳида нигоҳ дошта мешаванд.

### 6.2. Шакли дуюми нормалӣ (2NF)

Ҷадвал бояд ба талаботи 1NF ҷавобгӯ бошад ва ҳар як атрибути ғайрикалидӣ аз тамоми калиди аввалия вобаста бошад.

Дар ҳамаи се ҷадвал калиди аввалия аз як майдон иборат аст. Аз ин рӯ, вобастагии қисмӣ вуҷуд надорад.

### 6.3. Шакли сеюми нормалӣ (3NF)

Ҷадвал бояд ба талаботи 2NF ҷавобгӯ бошад ва вобастагии транзитивии атрибутҳои ғайрикалидӣ вуҷуд надошта бошад.

Маълумоти истифодабарандагон, мизҳо ва фармоишҳо дар муносибатҳои алоҳида нигоҳ дошта мешаванд. Дар ҷадвали RESERVATIONS ба ҷойи такрор кардани маълумоти мизоҷ ва миз танҳо идентификаторҳои онҳо истифода мешаванд.

Модели пешниҳодшуда ба талаботи асосии шаклҳои 1NF, 2NF ва 3NF ҷавобгӯ мебошад.

## 7. Индексгузорӣ

Барои беҳтар намудани самаранокии ҷустуҷӯ индексҳо пешбинӣ мешаванд:

| Ҷадвал | Майдон | Таъинот |
|---|---|---|
| USERS | email | Ҷустуҷӯи истифодабаранда |
| DINING_TABLES | table_number | Ҷустуҷӯи миз |
| RESERVATIONS | user_id | Ҷустуҷӯи фармоишҳои мизоҷ |
| RESERVATIONS | table_id | Ҷустуҷӯи фармоишҳои миз |
| RESERVATIONS | status | Филтр аз рӯи ҳолати фармоиш |
| RESERVATIONS | reservation_start | Ҷустуҷӯ аз рӯи сана ва вақт |

## 8. Хулоса

Дар натиҷаи таҳияи модели мантиқӣ сохтори муносибатии пойгоҳи додаҳои системаи бронированияи мизҳо муайян карда шуд.

Модел аз се муносибати асосӣ иборат буда, калидҳои аввалия, калидҳои хориҷӣ, робитаҳо ва маҳдудиятҳои якпорчагии маълумотро дар бар мегирад.

Модели мантиқӣ ба талаботи асосии нормализатсия ҷавобгӯ буда, барои таҳияи модели физикӣ ва скриптҳои SQL замина фароҳам меорад.
