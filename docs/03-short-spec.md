
# 03. Мушаххасоти кӯтоҳи техникӣ

## 3.1. Маълумоти умумӣ

**Номи лоиҳа:** Веб-барномаи банд кардани мизҳо дар тарабхона.

**Мавзӯи лоиҳа:** Коркарди веблоиҳаи банд кардани мизҳо дар тарабхона.

**Навъи система:** Веб-барнома.

**Соҳаи истифода:** Хизматрасонии тарабхонаҳо.

**Мақсади таҳия:** Автоматикунонии раванди банд кардани мизҳо, коркарди дархостҳои мизоҷон ва идоракунии бронкуниҳо.

## 3.2. Асос барои таҳияи система

Асоси таҳияи система зарурати беҳтар намудани раванди банд кардани мизҳо дар тарабхона ва кам кардани мушкилоте мебошад, ки ҳангоми истифодаи усулҳои анъанавии бронкунӣ ба вуҷуд меоянд.

Система бояд раванди интихоби миз, муайян кардани сана ва вақт, сабти дархост ва идоракунии бронкуниҳоро тавассути интерфейси веб таъмин намояд.

## 3.3. Мақсад ва вазифаҳои система

Мақсади асосии система фароҳам овардани воситаи рақамӣ барои банд кардани мизҳо ва идоракунии бронкуниҳо дар тарабхона мебошад.

Барои ноил шудан ба ин мақсад вазифаҳои зерин муайян карда мешаванд:

- Ташкили бақайдгирӣ ва воридшавии корбарон;
- Таъмини дастрасӣ ба маълумоти тарабхона;
- Намоиши рӯйхати мизҳо;
- Намоиши ғунҷоиши ҳар як миз;
- Интихоби сана ва вақти ташриф;
- Муайян кардани шумораи меҳмонон;
- Санҷиши дастрасии миз;
- Сабти дархостҳои бронкунӣ;
- Идоракунии бронкуниҳои мизоҷон;
- Таъмини имконияти бекор кардани бронкунӣ;
- Ташкили панели маъмурӣ;
- Идоракунии мизҳо ва маълумоти бронкунӣ.

## 3.4. Иштирокчиёни система

Система се гурӯҳи асосии корбаронро дар бар мегирад.

### 3.4.1. Мизоҷ

Мизоҷ шахсест, ки барои истифодаи хизматрасонии тарабхона мизро банд мекунад.

Ҳуқуқ ва имкониятҳо:
- Бақайдгирӣ дар система;
- Воридшавӣ ба ҳисоби шахсӣ;
- Дидани маълумоти тарабхона;
- Дидани рӯйхати мизҳо;
- Интихоби сана ва вақти ташриф;
- Муайян кардани шумораи меҳмонон;
- Фиристодани дархости бронкунӣ;
- Дидани таърихи бронкуниҳо;
- Дидани ҳолати дархост;
- Бекор кардани бронкунӣ мувофиқи қоидаҳои система.

### 3.4.2. Маъмур

Маъмур шахсест, ки фаъолияти умумии системаро идора мекунад.

Ҳуқуқ ва имкониятҳо:
- Воридшавӣ ба панели маъмурӣ;
- Дидани рӯйхати корбарон;
- Идоракунии маълумоти мизоҷон;
- Илова намудани мизҳои нав;
- Таҳрир ва нест кардани маълумоти мизҳо;
- Дидани ҳамаи бронкуниҳо;
- Тасдиқ ё рад кардани дархостҳо;
- Тағйир додани ҳолати бронкунӣ;
- Назорати фаъолияти система.

### 3.4.3. Корманди тарабхона

Корманди тарабхона шахсест, ки дар раванди коркарди бронкуниҳо ва хизматрасонии мизоҷон иштирок мекунад.

Ҳуқуқ ва имкониятҳо:
- Воридшавӣ ба ҳисоби корманд;
- Дидани рӯйхати бронкуниҳо;
- Дидани маълумоти мизоҷон;
- Баррасии дархостҳои нав;
- Тасдиқ ё рад кардани дархостҳо;
- Навсозии ҳолати бронкунӣ дар доираи ҳуқуқҳои додашуда.

## 3.5. Талаботи функсионалӣ

Талаботи функсионалӣ имкониятҳоеро муайян мекунанд, ки система бояд иҷро намояд.

| Рамз | Талабот |
|---|---|
| FR-01 | Система бояд бақайдгирии корбаронро таъмин намояд. |
| FR-02 | Система бояд воридшавӣ ва баромадан аз ҳисобро таъмин намояд. |
| FR-03 | Система бояд маълумоти тарабхонаро намоиш диҳад. |
| FR-04 | Система бояд рӯйхати мизҳои тарабхонаро нишон диҳад. |
| FR-05 | Система бояд ғунҷоиши ҳар як мизро нишон диҳад. |
| FR-06 | Система бояд интихоби сана ва вақтро таъмин намояд. |
| FR-07 | Система бояд шумораи меҳмононро қабул намояд. |
| FR-08 | Система бояд дастрасии мизро дар вақти интихобшуда санҷад. |
| FR-09 | Система бояд дархости бронкуниро сабт намояд. |
| FR-10 | Система бояд ҳолати бронкуниро нигоҳ дорад. |
| FR-11 | Система бояд имконияти дидани бронкуниҳои шахсиро таъмин намояд. |
| FR-12 | Система бояд бекор кардани бронкуниро таъмин намояд. |
| FR-13 | Система бояд ба маъмур имконияти идоракунии мизҳоро диҳад. |
| FR-14 | Система бояд ба маъмур имконияти идоракунии бронкуниҳоро диҳад. |
| FR-15 | Система бояд имконияти тасдиқ ё рад кардани дархостҳоро таъмин намояд. |
| FR-16 | Система бояд ҳуқуқҳои дастрасии корбаронро мувофиқи нақшашон маҳдуд намояд. |

## 3.6. Талаботи ғайрифунксионалӣ

Талаботи ғайрифунксионалӣ хусусиятҳои сифатӣ ва маҳдудиятҳои кори системаро муайян мекунанд.

### 3.6.1. Амният
- Маълумоти корбарон бояд ҳифз карда шавад.
- Паролҳо бояд дар шакли ҳифзшуда нигоҳ дошта шаванд.
- Дастрасӣ ба панели маъмурӣ бояд маҳдуд бошад.
- Ҳар як амали корбар бояд мувофиқи ҳуқуқҳои муайяншуда иҷозат дода шавад.

### 3.6.2. Қулайии истифода
- Интерфейс бояд одӣ ва фаҳмо бошад.
- Система бояд барои истифодабарандагони дорои сатҳи гуногуни дониши техникӣ мувофиқ бошад.
- Саҳифаҳо бояд дар дастгоҳҳои гуногун дуруст намоиш дода шаванд.

### 3.6.3. Эътимоднокӣ
- Маълумоти бронкуниҳо бояд дуруст нигоҳ дошта шавад.
- Система бояд аз бронкунии такрории як миз дар фосилаи вақти якхела пешгирӣ намояд.
- Ҳангоми хатогӣ система бояд паёми мувофиқ нишон диҳад.

### 3.6.4. Самаранокӣ
- Саҳифаҳо бояд дар вақти муносиб бор карда шаванд.
- Ҷустуҷӯ ва намоиши маълумот бояд самаранок иҷро шаванд.
- Коркарди дархостҳо набояд боиси аз даст рафтани маълумот гардад.

## 3.7. Қоидаҳои асосии бизнес

Ҳангоми коркарди система қоидаҳои зерин бояд риоя карда шаванд:

1. Бронкунӣ бояд ба мизоҷи муайян тааллуқ дошта бошад.
2. Сана ва вақти бронкунӣ бояд ба вақти оянда тааллуқ дошта бошанд.
3. Шумораи меҳмонон набояд аз ғунҷоиши мизи интихобшуда зиёд бошад.
4. Як миз дар фосилаи вақти якхела набояд бронкунии тасдиқшудаи такрорӣ дошта бошад.
5. Дархости нав бояд ҳолати ибтидоии «Дар интизори баррасӣ»-ро дошта бошад.
6. Маъмур ё корманди дорои ҳуқуқ бояд дархостро тасдиқ ё рад карда тавонад.
7. Бронкунии бекоршуда набояд ҳамчун бронкунии фаъол ҳисобида шавад.
8. Танҳо корбарони дорои ҳуқуқи мувофиқ метавонанд маълумоти идоракуниро тағйир диҳанд.

## 3.8. Ҳолатҳои бронкунӣ

Барои идоракунии раванди бронкунӣ ҳолатҳои зерин муайян карда мешаванд:

| Ҳолат | Маъно |
|---|---|
| pending | Дархост дар интизори баррасӣ мебошад. |
| confirmed | Бронкунӣ тасдиқ шудааст. |
| rejected | Дархост рад карда шудааст. |
| cancelled | Бронкунӣ бекор карда шудааст. |
| completed | Хизматрасонӣ анҷом ёфтааст. |

Ҳолати бронкунӣ бояд дар система нигоҳ дошта шуда, барои мизоҷ ва кормандони дорои ҳуқуқ намоиш дода шавад.

## 3.9. Маълумоти асосии система

Система бояд маълумоти зеринро нигоҳ дорад:

- Маълумоти корбарон;
- Маълумоти мизоҷон;
- Маълумоти кормандон;
- Маълумоти мизҳои тарабхона;
- Ғунҷоиши мизҳо;
- Сана ва вақти бронкунӣ;
- Шумораи меҳмонон;
- Ҳолати бронкунӣ;
- Маълумоти иловагӣ оид ба дархост.

Маълумоти мазкур дар базаи додаҳо нигоҳ дошта шуда, барои иҷрои амалиётҳои система истифода мешавад.

## 3.10. Маҳдудиятҳои система

Дар доираи версияи ибтидоии лоиҳа маҳдудиятҳои зерин муайян карда мешаванд:

- Система барои идоракунии бронкунии мизҳо дар тарабхона пешбинӣ шудааст.
- Бронкунӣ танҳо барои сана ва вақти муайян анҷом дода мешавад.
- Дастрасии миз аз рӯйи бронкуниҳои мавҷуда санҷида мешавад.
- Имконияти пардохти онлайн дар доираи вазифаҳои ҳатмии версияи ибтидоӣ пешбинӣ нашудааст.
- Имкониятҳои иловагӣ метавонанд дар марҳилаҳои минбаъдаи таҳия илова карда шаванд.

## 3.11. Натиҷаи интизоршаванда

Дар натиҷаи татбиқи лоиҳа веб-барномаи корӣ таҳия карда мешавад, ки ба мизоҷон имконияти банд кардани мизҳоро фароҳам оварда, ба маъмурон ва кормандони тарабхона воситаҳои идоракунии бронкуниҳоро пешниҳод менамояд.

Система бояд равандҳои асосии бронкунӣ, санҷиши дастрасии миз, коркарди дархостҳо ва идоракунии маълумотро автоматӣ гардонад.

## 3.12. Меъёрҳои қабули система

Система дар ҳолати иҷро шудани шартҳои зерин ба талаботи асосӣ ҷавобгӯ ҳисобида мешавад:

1. Корбар метавонад дар система бақайдгирӣ ва воридшавӣ кунад.
2. Мизоҷ метавонад миз ва вақти ташрифро интихоб намояд.
3. Система дастрасии мизро дуруст санҷад.
4. Дархости бронкунӣ дар базаи додаҳо сабт шавад.
5. Маъмур тавонад дархостро тасдиқ ё рад кунад.
6. Мизоҷ тавонад ҳолати бронкунии худро бинад.
7. Система аз бронкунии такрории миз дар як фосилаи вақт пешгирӣ кунад.
8. Ҳуқуқҳои мизоҷ, корманд ва маъмур аз ҳам ҷудо карда шаванд.

## 3.13. Хулоса

Дар ин боб мушаххасоти кӯтоҳи техникии веб-барномаи банд кардани мизҳо дар тарабхона таҳия карда шуд. Дар он мақсад, вазифаҳо, иштирокчиён, талаботи функсионалӣ ва ғайрифунксионалӣ, қоидаҳои бизнес ва меъёрҳои қабули система муайян гардиданд.

Ин ҳуҷҷат ҳамчун асос барои моделсозии рафтори система, таҳияи диаграммаҳои UML ва тарҳрезии базаи додаҳо истифода мешавад.
