
# Система бронирования столов в ресторане

## 1. Маълумоти умумӣ

Лоиҳаи «Системаи бронирования столов в ресторане» барои таҳияи веб-барнома пешбинӣ шудааст, ки ба мизоҷон имкон медиҳад мизҳои тарабхонаро пешакӣ фармоиш диҳанд.

Система раванди қабули фармоишҳоро автоматӣ намуда, ба кормандони тарабхона ва маъмурият имконият медиҳад, ки фармоишҳо ва мизҳоро идора кунанд.

## 2. Мақсади лоиҳа

Мақсади асосии лоиҳа таҳияи веб-система барои содда намудани раванди фармоиши мизҳо, беҳтар намудани хизматрасонӣ ба мизоҷон ва самаранок идора кардани фармоишҳо дар тарабхона мебошад.

## 3. Вазифаҳои асосӣ

- Омода намудани интерфейси веб барои мизоҷон.
- Таъмини имконияти бақайдгирӣ ва воридшавӣ ба система.
- Намоиши маълумот дар бораи мизҳои тарабхона.
- Санҷидани дастрасии мизҳо барои сана ва вақти интихобшуда.
- Фармоиш додани миз аз ҷониби мизоҷ.
- Намоиши рӯйхати фармоишҳо.
- Идоракунии фармоишҳо аз ҷониби кормандон.
- Идоракунии мизҳо ва истифодабарандагон аз ҷониби маъмур.

## 4. Иштирокчиёни система

| Иштирокчӣ | Вазифа |
|---|---|
| Мизоҷ | Дидани мизҳо ва фармоиш додани онҳо |
| Корманд | Дидан ва коркарди фармоишҳо |
| Маъмур | Идоракунии мизҳо, истифодабарандагон ва система |

## 5. Функсияҳои асосӣ

### Барои мизоҷ
- Бақайдгирӣ ва воридшавӣ.
- Дидани маълумоти тарабхона.
- Дидани мизҳои дастрас.
- Санҷидани сана ва вақти озод.
- Фармоиш додани миз.
- Дидани фармоишҳои шахсӣ.
- Бекор кардани фармоиш.

### Барои корманд
- Дидани фармоишҳои воридшуда.
- Тасдиқ ё рад кардани фармоиш.
- Тағйир додани ҳолати фармоиш.

### Барои маъмур
- Илова ва таҳрири мизҳо.
- Нест кардани мизҳо.
- Идоракунии истифодабарандагон.
- Назорат ва идоракунии фармоишҳо.

## 6. Қоидаҳои асосии бизнес

- Як мизро дар як вақт барои фармоишҳои бо ҳам мувофиқ такроран банд кардан мумкин нест.
- Фармоиш бояд сана ва вақти муайян дошта бошад.
- Мизоҷ метавонад фармоиши худро бекор кунад.
- Корманд метавонад фармоишро тасдиқ ё рад намояд.
- Ҳолати ҳар як фармоиш бояд дар система нигоҳ дошта шавад.
