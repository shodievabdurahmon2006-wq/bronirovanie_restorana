# Dastarkhon | Веблоиҳаи банд кардани мизҳо

## Технологияҳо
- PHP 8+
- MySQL / MariaDB
- HTML5, CSS3
- PDO барои пайвастшавии бехатар ба пойгоҳи додаҳо

## Насб дар XAMPP
1. Папкаи `restaurant_booking`-ро ба `C:\xampp\htdocs\` нусха кунед.
2. XAMPP Control Panel-ро кушода, Apache ва MySQL-ро фаъол кунед.
3. Дар браузер `http://localhost/phpmyadmin`-ро кушоед.
4. Ҷадвали **Import**-ро интихоб карда, файли `database.sql`-ро ворид кунед.
   Ин файл пойгоҳи додаи `restaurant_booking` ва маълумоти намунавиро месозад.
5. Агар логин ё рамзи MySQL-и шумо аз танзимоти стандартӣ фарқ кунад, файли `config.php`-ро таҳрир кунед.
6. Лоиҳаро кушоед: `http://localhost/restaurant_booking/`

## Дохилшавӣ ба панели маъмур
- Суроға: `http://localhost/restaurant_booking/admin/login.php`
- Номи корбар: `admin`
- Рамз: `password`

**Муҳим:** пеш аз истифодаи воқеӣ рамзи маъмурро иваз кунед. Барои кори истеҳсолӣ инчунин CSRF protection, маҳдудкунии кӯшишҳои воридшавӣ, тасдиқи SMS ва қоидаҳои дақиқи минтақаи вақтро илова кардан лозим аст.

## Имкониятҳо
### Меҳмон
- Интихоби сана, вақт, шумораи меҳмонон ва толор.
- Интихоби худкори мизи холӣ бо шумораи ҷойҳои кофӣ.
- Сабти дархост бо ном ва рақами телефон.
- Дидани рақами дархост ва ҳолати ибтидоии он.

### Маъмур
- Воридшавии маъмур.
- Дидани бандҳои рӯз ва филтр аз рӯи сана.
- Тасдиқ ё бекор кардани дархост.
- Илова кардани толор ва миз.
- Фаъол ё ғайрифаъол кардани миз.
- Нақшаи ҳолати мизҳо: сабз — холӣ, сурх — дорои банд.

## Қоидаи вақт
Ҳар банд мизро барои 2 соат нигоҳ медорад. Вақти корӣ дар ин намуна аз 10:00 то 23:00 аст. Дар шакли меҳмон вақти оғози банд аз 10:00 то 22:00 интихоб мешавад.

## Сохтори асосии база
- `users` — корбарон ва маъмурон
- `halls` — толорҳо
- `tables` — мизҳо ва шумораи ҷойҳо
- `bookings` — дархостҳои бандкунӣ

## Эзоҳ
Ин версияи таълимӣ мебошад. Барои санҷиш ва таҳияи курсовая пешбинӣ шудааст. Таърихи бандкунии меҳмон бо рақами телефон дар ҷадвали `bookings` нигоҳ дошта мешавад, аммо саҳифаи шахсии меҳмон/сабти ном дар ин версияи ибтидоӣ ворид карда нашудааст.
